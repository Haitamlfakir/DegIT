# DegiT — Digital Agency Website

A responsive three-page agency website built with React, Vite, React Router and CSS.

## Pages
- **About us** — introduces DegiT, the team and its approach to digitalizing businesses.
- **Our projects** — presents three editable project showcase examples.
- **What we offer** — interactive service selector with service details and a quote link.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Open this folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Customize
- Edit project examples in `src/pages/Projects.jsx`.
- Edit services and included features in `src/pages/Offer.jsx`.
- Change the contact email in `src/App.jsx` and `src/pages/Offer.jsx`.
- Update colors, spacing and typography in `src/styles.css`.

The projects shown are sample portfolio concepts. Replace them with real client work before publishing.
